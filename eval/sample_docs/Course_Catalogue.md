# CS450 Advanced Databases

CS450 Advanced Databases requires CS320 Data Structures as a prerequisite. A student who has not passed CS320 must ask the Registrar for a prerequisite waiver before enrolling.

# CS320 Data Structures

CS320 Data Structures is taught every autumn by Professor Ada Lovelace and is open to second-year students.
